# Checklist reprise fiches produits affiliation

Utilise cette checklist pour chaque fiche. Coche au fur et a mesure.
Objectif : passer de "correct" a "top SEO + conversion + E-E-A-T Google".

---

## 1. Introduction (le premier paragraphe sous le titre)

- [ ] Reecrire l'intro pour qu'elle soit **unique a ce produit** (pas de phrase generique reutilisable pour un autre)
- [ ] Mentionner **au moins 1 element concret** : nom de la marque + modele + chiffre cle (dB, age, poids)
- [ ] Integrer **le mot-cle principal** dans les 100 premiers caracteres
- [ ] Parler au lecteur : "votre bebe", "votre enfant" (pas "le bebe" impersonnel)
- [ ] Eviter les superlatifs non sources ("le meilleur", "le plus confortable")

**Exemple a retravailler** :
> ~~"Pour que bebe profite de chaque moment en toute serenite. Concerts, festivals..."~~
> → "Votre bebe de 8 mois qui pleure au premier petard du 14 juillet ? Le Muffy Baby d'Alpine reduit le bruit de 23 dB — l'equivalent d'un feu d'artifice qui devient un concert en appartement..."

---

## 2. Section benefices (bullet list sous le titre)

- [ ] 4 a 6 benefices, pas plus (sinon on dilue)
- [ ] Chaque benefice commence par un **verbe d'action** ou une **caracteristique mesurable**
- [ ] Inclure **1 chiffre par benefice** si possible (dB, age, poids, duree de garantie)
- [ ] Eviter les benefices redondants (ex: "leger" + "ultra-leger")
- [ ] **Trier par importance** : le plus vendeur en premier

**Checklist specifique** :
- [ ] Reduction dB exacte (pas "eleve")
- [ ] Age exact (pas "petit enfant")  
- [ ] Norme CE citee textuellement (EN 352-1:2020)
- [ ] Argument emotion + 1 argument rationnel minimum

---

## 3. Section "Pourquoi choisir ce produit ?"

- [ ] **3 a 5 arguments** max (au-dela le lecteur decroche)
- [ ] Chaque argument = **paragraphe court** (2-3 lignes max), pas juste une phrase
- [ ] Format : `<strong>Argument</strong> : explication concrete avec exemple`
- [ ] Inclure **au moins 1 donnee verifiable** par argument
- [ ] **Citer la source quand tu fais une affirmation forte** (ex: "selon l'OMS, au-dela de 85 dB...")

---

## 4. Section "Dans quelles situations l'utiliser ?"

- [ ] Lister **5 a 7 situations concretes** (pas des generalites)
- [ ] **Nommer les evenements/lieux precis** ("Feux d'artifice du 14 juillet" plutot que "feu d'artifice")
- [ ] Inclure au moins **1 situation non-evidente** qui surprend (ex: "travaux de voisinage", "cafe bruyant", "trajet en TER")
- [ ] Lier chaque situation a un **chiffre dB** si pertinent

---

## 5. Section "Caracteristiques techniques"

**Infos MINIMUM a ajouter** (souvent manquantes dans mes fiches) :
- [ ] **Poids** du casque en grammes
- [ ] **Dimensions** de la boite / du casque
- [ ] **Tour de tete** compatible (cm)
- [ ] **Materiaux precis** : pas juste "mousse" mais "polyurethane + ABS + acier inox"
- [ ] **Certifications exactes** : CE + norme europeenne
- [ ] **Pays de fabrication**
- [ ] **Garantie fabricant** (2 ans ? 1 an ?)
- [ ] **Contenu de la boite** (liste exhaustive)
- [ ] **Conseils d'entretien** (lavable en machine ? temperature ?)

**Source** : fiche produit officielle Vertbaudet + site marque (alpine-hearing.com, kidywolf.be, alecto.eu, dooky.eu)

---

## 6. Section FAQ

- [ ] **6 a 8 questions** minimum (plus c'est mieux pour le schema FAQPage)
- [ ] Questions **formulees comme les utilisateurs** (vois Keyword Shitter : "a partir de quel age", "comment le mettre", "est-il lavable")
- [ ] Reponses **longues** (minimum 40 mots par reponse pour Google)
- [ ] **Inclure le mot-cle** dans la reponse quand naturel
- [ ] **1 question differenciante** par produit (qui ne marcherait pas pour un autre)

**Idees de questions frequentes a ajouter** :
- Est-ce que je peux le laver en machine ?
- Quelle est la garantie ?
- Est-il livre dans un etui ?
- Convient-il pour un enfant TDAH / autiste ?
- Peut-on le mettre pendant le sommeil ?
- Combien de temps peut-on le porter d'affilee ?
- Est-il fabrique en Europe ?

---

## 7. Maillage interne

- [ ] **Minimum 3 liens internes** par fiche (hors bloc "À noter")
- [ ] Au moins **1 lien vers la collection** (`/collections/casque-anti-bruit-bebe`)
- [ ] Au moins **1 lien vers un autre produit** (cross-sell / comparaison)
- [ ] Si l'article de blog correspondant est redige : **lien vers l'article**
- [ ] Si la marque a une page dediee : **lien vers `/marques/[brand]`**
- [ ] Ancres **naturelles** dans le texte (pas "cliquez ici" ou "casque-anti-bruit-bebe")

**Ancres a privilegier** :
- "casque anti-bruit" (generique, collection)
- "Alpine Muffy Baby" (nom produit, fiche)
- "guide d'achat" (vers blog)
- "dès 4 ans" (vers produit age specifique)

---

## 8. Claims & E-E-A-T (expertise, autorite)

- [ ] **Sourcer toute affirmation medicale** (citer OMS, INSERM, ANSES, ou article ORL)
- [ ] **Ne pas affirmer** qu'un produit "aide" les enfants TDAH/TSA sans source (claim thérapeutique risque)
- [ ] Preferer **"de nombreux parents rapportent..."** a **"clinically proven"**
- [ ] Si tu as teste le produit : **ajoute un paragraphe "Notre avis"** signe
- [ ] Ajouter **l'annee** dans les affirmations ("En 2026...", "depuis 1995...")

---

## 9. Images (deja bon, a verifier)

- [ ] 3 images minimum par variante
- [ ] **Alt** descriptif (pas juste "Casque")
- [ ] WebP (deja fait)
- [ ] La 1ere image est la **plus vendeuse** (produit bien visible, pas d'emballage)
- [ ] Eventuellement 1 image **lifestyle** (enfant portant le casque)

---

## 10. Subtitle / Meta description

- [ ] **Subtitle** : 1 phrase d'accroche, **unique**, avec emotion + chiffre cle (max 140 chars)
- [ ] **Meta description** : **entre 150 et 160 chars**, incluant le mot-cle principal + 1 benefice + 1 CTA implicite ("Livraison rapide", "Certifie CE", etc.)

---

## 11. SEO Title (H1 tag + meta title)

- [ ] **Meta title** : entre 50 et 60 chars, marque + modele + chiffre cle + Geniuz
- [ ] **H1** (le titre du produit) : identique ou tres proche du meta title
- [ ] Eviter le doublon "Geniuz | Geniuz"

---

## 12. Differenciation entre produits similaires

Pour les modeles tres proches (ex: Muffy Baby classique vs Menthe edition) :
- [ ] **Reecrire completement** 2 des 3 sections principales
- [ ] Mettre en avant **un angle different** (Menthe edition → "cadeau naissance original", "photos souvenirs")
- [ ] Eviter le **copier-coller avec changement de mots** que Google reperre

---

## Ordre de priorite pour retravailler

Par importance (trafic potentiel) :
1. **Muffy Baby** (classique) - produit phare, a tester soi-meme
2. **Muffy Kids** - grosse niche 3-16 ans
3. **Kidynoise Kidywolf** - bon rapport qualite/prix, concurrents faibles
4. **Alecto 29dB** - angle "TDAH / ecole", niche peu concurentielle mais sensible legalement
5. **Dooky Evolutif** - argument unique "2-en-1 0-6 ans"
6. **Dooky Protection** + **Alecto Bebes** - entree de gamme, moins prioritaires
7. **Muffy Baby Menthe** - simple edition coloree, le moins critique

---

## Temps estime par fiche

- Fiche basique retravaillee avec checklist cochee : **45 min - 1h**
- Fiche avec test produit reel (achat, photos, 2 semaines d'usage) : **3h - 4h**

---

## Outils recommandes

- **YourTextGuru** ou **1.fr** : analyse semantique (mots-cles satellites a integrer)
- **Hemingway Editor** : verifier lisibilite (cible : niveau college / CE2)
- **Google Search Console** : voir les requetes qui amenent deja du trafic
- **Chrome devtools / Lighthouse** : verifier le poids final de la page produit
