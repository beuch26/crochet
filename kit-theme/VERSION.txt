v2.9.7 (2025-11-11) - Fix hero collé au header quand offset = 0
--------------------
🔧 FIX - Comportement offset corrigé:
   - Avant: offset à 0 laissait un espace entre header et hero
   - Maintenant: offset à 0 = hero collé au header (pas d'espace)
   - Script définit variable CSS --header-height dynamiquement
   - Hero utilise calc() pour compenser le padding du main-content

🎯 NOUVELLE FORMULE:
   - margin-top = calc(-1 × header-height + offset)
   - offset = 0   → collé au header (0px d'espace)
   - offset = +20 → 20px d'espace sous le header
   - offset = -20 → chevauche le header de 20px

✅ RÉSULTAT:
   - Comportement intuitif et prévisible
   - 0 signifie vraiment "pas d'espace"
   - Contrôle précis de l'espacement/chevauchement

📍 FICHIERS MODIFIÉS:
   - layout/theme.liquid (CSS variable --header-height)
   - sections/hero-banner.liquid (calc() + doc)

```javascript
const dropdownLinks = $$('.nav-item.has-dropdown > .nav-link');

    e.preventDefault();
    navItem.classList.toggle('expanded');
```

AFTER:
```javascript
const dropdownItems = $$('.nav-item.has-dropdown');
dropdownItems.forEach(navItem => {
  const link = navItem.querySelector('.nav-link');
  if (link) {
    link.addEventListener('click', (e) => {
      e.preventDefault();
      e.stopPropagation(); // Évite propagation
      navItem.classList.toggle('expanded');
      console.log('Dropdown toggled:', navItem.classList.contains('expanded'));
    });
  }
});
```
